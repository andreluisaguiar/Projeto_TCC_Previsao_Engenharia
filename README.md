# Projeto de TCC: Processamento de Linguagem Natural Aplicado à Predição de Trajetórias Acadêmicas no BICT - UFMA

Este projeto utiliza técnicas de Processamento de Linguagem Natural (PLN) para prever a escolha de engenharia a partir de títulos de Trabalhos de Conclusão de Curso (TCC) no Bacharelado Interdisciplinar em Ciência e Tecnologia (BICT).

## Funcionalidades

1. **Coleta de Dados**: Coleta de dados de monografias a partir de uma URL fornecida.
2. **Remoção de Duplicatas**: Remoção de duplicatas dos dados coletados.
3. **Detecção de Outliers**: Detecção de outliers com base na similaridade semântica entre títulos e engenharias.
4. **Análise e Treinamento**: Análise dos dados e treinamento de modelos de machine learning para prever a engenharia.
5. **Predição de Engenharia**: Previsão da engenharia com base em um título de TCC fornecido.
